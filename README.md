# Multi-Modal Image Retrieval System

## Overview
This project implements a multi-modal image retrieval system that takes a text query and retrieves the top-K matching images from a dataset.

## Requirements
- Python 3.8+
- Flask
- PyTorch
- sentence-transformers
- FAISS
- PIL (Pillow)
- Torchvision
